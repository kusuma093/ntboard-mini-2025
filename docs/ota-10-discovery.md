# 1.0.0-ota.10

- เปิดเครื่องค้นหา Slave ID 1–5 แยก Serial1 (XYMD02) และ Serial2 (PM2230)
- รอบปกติอ่านเฉพาะอุปกรณ์ที่ตอบสำเร็จ และพัก 2 นาทีหลังจบรอบ
- อุปกรณ์เดิมอ่านไม่สำเร็จ 3 รอบติดต่อกันจะพัก แล้วค้นหาใหม่ในรอบ discovery
- ทุกประมาณ 10 นาทีเริ่มรอบค้นหาเต็มอีกครั้ง หากกำลังอ่านหรือ OTA จะรอจบก่อน เวลาเจออุปกรณ์ใหม่รวมเวลาสแกนด้วย
- มิเตอร์ต้องอ่านครบทุก register ก่อนนับว่าพบและส่งข้อมูล ไม่ส่งค่าบางส่วนเมื่ออ่านล้มเหลว
- รายการที่พบเก็บใน RAM รีบูตแล้วค้นหาใหม่ เหมาะกับการย้ายหรือต่ออุปกรณ์เพิ่มโดยไม่แก้โค้ด
- คง JSON/topic, การรีบูตเที่ยงคืน และการรองรับ SD แบบไม่บังคับจาก .9

ตรวจ Serial: `[DISCOVERY] ... found` เมื่อพบอุปกรณ์ และ `failed 3 rounds` เมื่อพักอุปกรณ์
รอบค้นหาจะยังมี timeout ของ ID ที่ไม่ได้ต่อ เป็นพฤติกรรมที่คาดหมายได้ รอบปกติไม่อ่าน ID เหล่านั้น
อุปกรณ์ใหม่ต้องใช้ ID 1–5 และค่าพอร์ตเดิม: XYMD02 9600 8N1; PM2230 9600 8E1

ทดสอบจริง: เปิดด้วย ID1, ดูว่ารอบถัดไปข้าม ID2–5, เพิ่ม ID2 แล้วรอรอบค้นหา, ถอด ID1 สามรอบแล้วต่อกลับและรอค้นพบใหม่ ตรวจทั้งสองพอร์ตแยกกัน
